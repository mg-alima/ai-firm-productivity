# Данные

В проекте используются микроданные двух волн опросов российских предприятий за 2023 и 2024 годы.

Исходные данные содержат конфиденциальную информацию и не могут быть опубликованы в открытом репозитории. Поэтому файлы с микроданными исключены из GitHub с помощью `.gitignore`.

В репозитории публикуются только код анализа, агрегированные результаты и визуализации, не содержащие идентифицирующих данных предприятий или респондентов.

## Размер выборок

- 2023 год — 1 200 предприятий;
- 2024 год — 1 212 предприятий;
- 545 предприятий удалось однозначно сопоставить между двумя волнами для панельного анализа.
